# 明清易代历史事件数据库 (1627–1662)

收录 **崇祯帝即位（1627）至南明永历帝遇难（1662）** 期间的重要历史事件，包含时间、地域、人名、分类四类信息，
存入本地 SQLite 数据库，并提供可交互网页：在自绘明末历史地图上按时间轴逐步展示事件、按事件分类着色。

## 目录结构

```
ming-events/
├── events.db              # 本地 SQLite 数据库（最终数据）
├── data/
│   ├── raw/*.jsonl        # 各批次事件原始数据（JSONL）
│   ├── gazetteer_north.csv / gazetteer_south.csv / gazetteer_extra.csv
│   │                      # 明代地名-坐标库（name,aliases,province,lat,lon）
│   └── china_provinces_v3.json   # 省界底图数据（DataV）
├── tools/
│   ├── build_map_data.py  # 省界 → 明代大区 GeoJSON
│   ├── build_db.py        # JSONL + gazetteer → events.db
│   ├── export_web.py      # events.db → web/data.js
│   └── qa_report.py       # 数据质检
├── index.html             # 站点入口（ming-events/ 即站点根）
├── web/
│   ├── app.js / style.css / data.js / ming_units.js
│   └── vendor/            # Leaflet 离线资源
└── serve.py               # 可选本地服务器
```

## 数据规模与内容

- 事件总数：**7804 条**（地图绘制 100% 带坐标）
- 时间跨度：**1627–1662**（崇祯即位 → 永历帝遇难、南明灭亡），432 个月中 431 个月有事件，1627–1662 逐年连续
- 字段：日期（公历年月日/月/年，三级精度）、地点（明代地名+经纬度+布政使司）、人物（6508 条带人物）、分类、摘要
- 分类（**通用分类体系**，适用于任何历史时期）：战争 2667 / 政治 2558 / 社会 735 / 灾害 513 / 起义 408 / 人物 397 / 外交 299 / 文化 227
  （原政权专属分类"南明/清朝"已归并入通用分类，原始分类保留于 `events.category_src` 字段供参考）
- 地名库：982 个明代地名（1973 个检索键），含政区、卫所、关隘、山川、域外诸地

## 使用方法

1. **查看网页**：入口为 `ming-events/index.html`（站点发布入口，`ming-events/` 即站点根）；本地预览运行 `python3 serve.py` 后访问 <http://127.0.0.1:8686/>
2. **全文检索**：`python3 tools/search.py 李定国 20`（中文任意子串，FTS5 二元组索引）
3. **查询数据库**：
   ```bash
   python3 -c "import sqlite3; con=sqlite3.connect('events.db'); print(con.execute('select count(*) from events').fetchone())"
   ```
   常用查询：按年份 `SELECT * FROM events WHERE year=1644;`、按人名 `SELECT * FROM events WHERE persons LIKE '%李定国%';`、
   全文检索 `SELECT e.* FROM events e JOIN events_fts f ON f.rowid=e.id WHERE events_fts MATCH '"李定 定国"'`
   （把查询词拆成二字词元短语：「李定国」→`"李定 定国"`，「扬州」→`"扬州"`；或直接用 `tools/search.py`，它自动转换）
4. **重新构建**：`python3 tools/build_db.py && python3 tools/export_web.py`

## 网页功能

- **时间轴滑动**（1627年1月–1662年12月）：事件按时间顺序在地图上出现；支持播放/暂停、速度（1月/3月/1年每步）、四种事件显示长度（近三月内[默认] / 近三年内 / 近十年内 / 累计出现）
- **按事件分类着色**：8 类通用分类各有专属颜色，图例可点击开关
- **分类筛选与关键词检索**（人名/地名/事件）
- **悬停事件点自动弹出说明小窗、移开自动关闭**（触屏可点击打开）；左侧列表可定位跳转
- 底图为自绘明末历史地图（政区设色 + 明代河流 + 明长城九边），无在线瓦片依赖，可离线使用

## 数据说明

事件数据为明末清初史料（《明史》《明史纪事本末》《明季北略》《明季南略》《南明野史》《小腆纪年附考》《清实录》《国榷》等）整理汇编而成，整理方法与已知局限如下：

- **日期**：按公历年月标注。明末行用大统历/时宪历与公历有差异，农历月换算公历约有 ±1 个月误差；只知年份者用 `YYYY`。少数跨年界事件（如崇祯十六年十二月事换算后已入 1644 年初）按叙事系年，年份误差已排除、月份容有出入。
- **存疑事件**：诸书记载有歧义者从通行说法并已在摘要中审慎表述。例如荥阳大会（1635-01，学界对其是否发生有争议）、杨嗣昌死法（自缢/服毒/病死三说）、李自成九宫山遇害（1645-05，公历或 6 月）、屠城类事件（扬州十日、嘉定三屠、江阴八十一日等）一律用"史称/史载"限定。
- **背景类条目**：约占四分之一的灾害、社会、一般诏令条目系据当年总体灾情与政令记载按府级细分安置，府县与月份为约置，不含虚构的战役、人名与官职。
- **地图**：标记点坐标为事件主地点（府/州/县/卫/所/关隘）今地近似值，误差一般在 20 公里内；大区界线为示意性简化，不代表精确历史疆域。
- **查重**：按（日期, 地点, 摘要）去重；不同人物的同类事件（如甲申殉节诸臣）各立一条，属不同事实而非重复。
